# k8s

Cluster-side pieces of the sandbox profiles (docs/profiles.md). Phase 3 material; nothing here has been applied to a cluster yet.

| Path | What | Status |
|---|---|---|
| `seccomp/vice-sandbox.json` | `Localhost` seccomp profile for R1 pods: Docker's default plus unconditional allow for `unshare`, `clone`/`clone3`, `setns`, `mount`, `umount2`, `pivot_root`, `mount_setattr`, `open_tree`, `move_mount`, `fsopen`/`fsconfig`/`fsmount`/`fspick`. Generated by `scripts/seccomp.py`. Install under `/var/lib/kubelet/seccomp/` on every node. | drafted, untested |
| `apparmor/vice-sandbox` | AppArmor profile for R1 pods: containerd's default minus `deny mount`, plus `mount`, `pivot_root`, `userns`. Load with `apparmor_parser`. | drafted, untested |
| `profiles/` | `namespace.yaml` (PSA labels), `runtimeclasses.yaml` (gvisor, kata, kata-gpu), `p1-workbench-pod.yaml`, `p2-background-job.yaml` | drafted, untested |
| `networkpolicy/egress-classes.yaml` | default-deny, DNS, ingress-from-proxy, N0–N3 by the `vice.cyverse.org/egress` label | drafted, untested |
| `agent-sandbox/sandboxtemplates.yaml` | P3 (gvisor) and P4 (kata-gpu) `SandboxTemplate`s, a warm pool, an example claim | drafted, untested |
| `kyverno/policies.yaml` | profile hardening rules (audit mode) and cosign keyless verification of `mesa-*` images | drafted, untested |
| `overlays/{js2,cyverse}` | kustomize overlays with cluster-specific CIDRs/handlers | drafted |
| `openbao/`, `egress-proxy/`, `approval-inbox/` | Phase 4 | next |

Verification for the two profiles (Phase 3 spike): a pod with `seccompProfile: {type: Localhost, localhostProfile: vice-sandbox.json}`, `appArmorProfile: {type: Localhost, localhostProfile: vice-sandbox}`, `hostUsers: false`, `allowPrivilegeEscalation: false`, `capabilities.drop: [ALL]` must run `bwrap --ro-bind / / --unshare-all --proc /proc true` successfully; Ubuntu 24.04 nodes additionally need `kernel.apparmor_restrict_unprivileged_userns=0` or a profile with `userns,` attached to `/usr/bin/bwrap`.
